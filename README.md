# AsthaOS: Astha Patel's Portfolio

**Live site:** https://asthaos.vercel.app

My portfolio, built as a small secure operating system. You "sign in" with MFA, land on a desktop, and open files to learn about me.

I'm a security analyst with an M.S. in Information Technology (Security) from Arizona State University. I'm open to Security Analyst, SOC and GRC roles, and also IT support.

## What's inside

| File | What it shows |
|---|---|
| `about_me.txt` | Who I am |
| `experience.log` | My work history as log entries |
| `projects/` | 11 security projects with GitHub links |
| `skills.exe` | Skills as installed modules |
| `certs.key` | Certifications |
| `resume.pdf` | My resume |
| `terminal` | Try `help`, `nmap astha` or `sudo hire-astha` |
| `spot_the_phish.app` | A 3-question phishing quiz |
| `do_not_open.exe` | A friendly ransomware joke |
| `Recycle Bin` | Results from my Azure honeypot |

Turn on **Matrix Mode** in the top bar for a different look.

## Built with
Next.js, React, Tailwind CSS and lucide-react. First built with v0 by Vercel, deployed on Vercel.
